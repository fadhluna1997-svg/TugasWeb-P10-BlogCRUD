# Tugas Web P10 - Blog CRUD Laravel

## Deskripsi

Project ini merupakan implementasi Blog CRUD menggunakan Laravel.
Aplikasi menyediakan fitur untuk membuat, membaca, mengubah, dan menghapus data post.

Project dibuat sebagai bagian dari tugas praktikum Web Development.

## Teknologi

- Laravel 11
- PHP 8.2
- MySQL
- Blade Template
- Bootstrap/Custom CSS
- Composer
- Git dan GitHub

## Database

Nama database:

`db_tugas_p10`

Konfigurasi database menggunakan MySQL melalui file `.env`.

Contoh konfigurasi:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=db_tugas_p10
DB_USERNAME=root
